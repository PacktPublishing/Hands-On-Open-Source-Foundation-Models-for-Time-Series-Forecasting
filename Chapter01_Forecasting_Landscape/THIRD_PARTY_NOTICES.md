- Source: <https://github.com/zhouhaoyi/ETDataset>.

- Original path: `ETT-small/ETTh1.csv`.
- Included copy: `data/ETTh1.csv`, distributed without changing the source bytes.
- SHA-256: `f18de3ad269cef59bb07b5438d79bb3042d3be49bdeecf01c1cd6d29695ee066`.
- Licence: Creative Commons Attribution-NoDerivatives 4.0 International;
  full text in `licenses/ETDataset_LICENSE.txt`.
- Source citation: Zhou et al., “Informer: Beyond Efficient Transformer for Long
  Sequence Time-Series Forecasting,” AAAI 2021; see the supplied `references.bib`.

Selection of the OT column and timestamp parsing occur in memory. The source CSV
remains unchanged. Forecasts, scores, and the experimental figures are outputs of
the chapter's code. Dataset source metadata is retained in
`results/data_source.json`.

- Provider: Salesforce AI Research and GIFT-Eval contributors.

- Frozen revision: `0b57dd6937eb9a69a3ae771f73ab36188bb33e47`.
- Included files: four published `all_results.csv` files and their `config.json`

- Licence: Apache License 2.0; full upstream notice in
  `licenses/GIFT-Eval_LICENSE.txt`.
- Individual source URLs and SHA-256 checksums are recorded in
  `results/gift_reference_manifest.json`.

`gift_reference.csv` is a chapter-generated reaggregation. It is not an original
GIFT model rerun, a current leaderboard, or an independently verified statement
about pretraining exposure. Upstream overlap flags are copied as metadata.

## Chronos-T5-Small

- Checkpoint: <https://huggingface.co/amazon/chronos-t5-small>.
- Frozen revision: `a971ba21945c4f1796b17a91fe69214b5f4ad472`.
- Model-card licence metadata: Apache License 2.0, preserved in
  `licenses/chronos_weight_metadata.txt`.
- Implementation: <https://github.com/amazon-science/chronos-forecasting>.

Weights are not bundled. The full experiment downloads them through the upstream
library. The experiment uses original Chronos-T5-Small, not Chronos-Bolt or
Chronos-2. ETTh1 pretraining overlap is recorded as unknown.

## Installed software and original teaching material

This archive does not vendor their implementation or pretrained weights.

The chapter's synthetic/conceptual illustrations are generated by original
Python code. The Forecasting Zoo plot uses the retained measured outputs. No
figures or text from the supplied reference books are redistributed here.
